# MEGA MARKET WORLD

Responsive starter interface for a multi-service marketplace.

## Run locally
1. Install Node.js (18 or newer).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Current status
This is a frontend starter/demo. It includes a responsive landing page, service cards, sample product cards, a working sample product search, and a country selector.

Authentication, database, real product inventory, seller onboarding, checkout, payments, shipping, food delivery, flights, hotels, rides, and travel bookings are not connected yet. Those require separate implementation, partner integrations, credentials, testing, and any applicable approvals.

The project is portable and can be developed in Replit, GitHub Codespaces, VS Code, or another compatible environment.
